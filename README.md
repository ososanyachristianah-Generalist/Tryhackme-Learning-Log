# Tryhackme-Learning-Log
## Sharing my learning journey on tryhackme 

### ROOM 1 - Offensive security intro
What I learnt - Think like an attacker to find weaknesses
Key takeaway - "dirb" command is used to find hidden directories/files on a website.

#### ROOM 2 - Defensive security intro
What I learnt - Access and cyber threat detection and response
Key takeaway - Defensive security is about spotting and stopping attacks, not just building walls.

#### ROOM 3 - Careers in cyber
What I learnt - There are many paths in cyber, not just "hacker" (SOC analyst, pentester, GRC, etc.)
Key takeaway - Different roles need different skills, so it's fine to explore before picking a lane.

#### ROOM 4 - Search skills
What I learnt - How to search effectively for solutions and documentation while working
Key takeaway - Knowing how to search well is as important as knowing the answer.

#### ROOM 5 - Inside a computer system
What I learnt - How CPU, memory, and storage work together to run a system
Key takeaway - Understanding the hardware basics makes it easier to understand how attacks work.

#### ROOM 6 - What is networking
What I learnt - How devices communicate using IP addresses and the TCP/IP model
Key takeaway - A LAN is just a group of connected devices sharing resources locally.

#### ROOM 7 - HTTP in detail
What I learnt - How requests and responses work between browser and server
Key takeaway - HTTP methods (GET, POST etc.) and status codes tell you what's really happening in a request.

#### ROOM 8 - DNS in detail
What I learnt - How domain names get translated into IP addresses
Key takeaway - DNS is like the internet's contact list, and it can be abused (e.g DNS spoofing).

#### ROOM 9 - Linux fundamentals part 1
What I learnt - Basic Linux navigation and commands
Key takeaway - "ls", "cd", "pwd" and "cat" are commands I'll be using constantly.

#### ROOM 10 - Nmap live host discovery
What I learnt - How to find which devices are alive on a network before scanning them
Key takeaway - "nmap -sn" sweeps a network to find live hosts without a full port scan.

#### ROOM 11 - Hydra
What I learnt - How brute-forcing login credentials works
Key takeaway - Weak passwords are still one of the easiest ways in.

#### ROOM 12 - Linux privesc (ongoing)
What I learnt - How a misconfigured sudo permission can let a regular user become root
Key takeaway - "sudo -l" shows what a user can run as root. GTFOBins lists programs that can be abused to escape into a root shell if sudo allows them
Command used - sudo find . -exec /bin/sh ; -quit
